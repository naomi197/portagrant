# PortaGrant submission checklist

## Check-in (before October 24, 2026 at 12:00 UTC)

- [ ] Public GitHub repository
- [ ] Current progress and outstanding items
- [ ] Architecture diagram (`docs/architecture.md`)
- [ ] Portaldot testnet contract address
- [ ] At least one create-grant transaction hash and explorer record
- [ ] Live demo or demo video under three minutes

## Final (before November 6, 2026 at 04:00 UTC)

- [ ] README explains setup, architecture, dependencies, and licenses
- [ ] At least three dated commits during the Hacker House period
- [ ] Contract address, deployment hash, and interaction hashes in `docs/deployment.md`
- [ ] Demo covers create, evidence submission, and milestone approval
- [ ] No substantial changes after code freeze

## Evidence policy

Do not replace pending values with invented addresses or hashes. Record every real transaction after deployment, including UTC timestamp, signer, method, and explorer URL.
